> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build V9.7.0 from the verified public V9.6.0 release, add evidence-gated Spotify detector contracts, complete safe-place verification before selling, move alert scanning behind a dedicated watchdog worker, and prove the protected C2/MiuMiu/PC Alarm paths do not regress.

**Architecture:** Keep the V9.6 release-overlay model. GitHub Actions downloads the exact V9.6.0 portable asset, verifies its SHA-256, extracts it, applies V9.7.0 patches/new modules, runs deterministic pytest regression suites, performs the real Windows launcher smoke, packages portable/update assets, verifies public hashes, and updates `latest.json` last. Detection lives in `spotify_detection_parity.py`; watchdog lifecycle lives in `spotify_watchdog.py`; safe-place state remains in `spotify_recovered_core.py`; `maple_nghia_pro.py` only bridges capture/config/events/sell gating.

**Tech Stack:** Python 3.12, pytest, OpenCV/Numpy already shipped by the app, Tkinter host, Git patch overlays, PowerShell, GitHub Actions `windows-latest`, existing Nghia launcher/updater packaging.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.7.0-spotify-detection-watchdog-parity-design.md`

## Global Constraints

- Base release: public stable `v9.6.0`; portable SHA-256 `fd74cb91e63c75dfff07421a4af413da201370b60cde3a615fec09a5c527282c`.
- Do not change C2 timing: Teleport 20..50 ms, Skill 20..50 ms, pair wait 0.05..0.15 s, outer hold 200..500 ms.
- Preserve PyDirectInput `PAUSE = 0.1`, cached-HWND focus path, MiuMiu seller, PC Alarm, launcher/updater, and `NghiaClientApp.exe` unless CI proves a packaging-only rebuild is required.
- Detector constants are evidence-backed, but exact CAPTCHA/full-bag assets are not currently recovered. No fallback detector may report `source="spotify_exact"`.
- CAPTCHA exact ROI is `(left=300, top=200, width=650, height=350)` only for 1280×720. Non-1280×720 exact Spotify detection is disabled; existing Nghĩa detection remains `nghia_fallback`.
- `CAPTCHA_THRESHOLD=0.70`, secondary CAPTCHA threshold `~0.68`, `FULL_BAG_DETECT_THRESHOLD=0.35`, `SELL_THRESHOLD=0.65`.
- Safe-place states are exactly `MOVE_SAFE -> SETTLE_SAFE -> VERIFY_SAFE -> SAFE_OK | SAFE_FAIL`; nominal settle 1.0 s; at most 6 verification attempts; reuse tolerance x=6/y=9.
- `SpotifyWatchdogWorker` has independent lifecycle, reads cached HWND/focus only, and never calls `_find_game_window` or `EnumWindows` in its loop.
- Watchdog cadence remains an explicitly labeled Nghĩa fallback derived from current alert-scan cadence; do not invent a Spotify watchdog interval.
- Do not implement active `session_monitor_worker` semantics or wire dormant FOCUS/SPAM/LAZY dynamic combos without new evidence and a spec amendment.
- STOP/restart/generation change must leave no behavior-owned input held.
- V9.7.0 is a separate release; never overwrite V9.6.0.

from dataclasses import dataclass
CAPTCHA_ROI=(300,200,650,350)
CAPTCHA_PRIMARY_THRESHOLD=0.70
CAPTCHA_SECONDARY_THRESHOLD=0.68
FULL_BAG_DETECT_THRESHOLD=0.35
SELL_THRESHOLD=0.65
SOURCE_EXACT='spotify_exact'; SOURCE_STRUCTURAL='spotify_structural'; SOURCE_NGHIA_FALLBACK='nghia_fallback'
_ALLOWED={SOURCE_EXACT,SOURCE_STRUCTURAL,SOURCE_NGHIA_FALLBACK}

@dataclass(frozen=True)
class SpotifyDetectionResult:
    kind:str; matched:bool; score:float|None; threshold:float|None; source:str

def crop_captcha_roi(frame,game_size):
    if tuple(game_size)!=(1280,720): raise ValueError('exact Spotify CAPTCHA ROI requires 1280x720')
    left,top,width,height=CAPTCHA_ROI
    return frame[top:top+height,left:left+width]

def score_result(kind,score,threshold,source,*,exact_asset=False):
    if source not in _ALLOWED: raise ValueError('unknown detector evidence source')
    if source==SOURCE_EXACT and not exact_asset: raise ValueError('spotify_exact requires recovered/validated exact asset path')
    score=float(score); threshold=float(threshold)
    return SpotifyDetectionResult(str(kind),score>=threshold,score,threshold,source)
```

import threading
class SpotifyWatchdogWorker:
    def __init__(self,host):
        self.host=host; self.generation=0; self.thread=None; self._stop=threading.Event()
    def start(self,cfg):
        if self.thread and self.thread.is_alive(): self.stop()
        self.generation+=1; generation=self.generation; self._stop.clear()
        self.thread=threading.Thread(target=self._run,args=(dict(cfg),generation),daemon=True,name='Nghia-Spotify-Watchdog')
        self.thread.start()
    def stop(self):
        self.generation+=1; self._stop.set(); t=self.thread
        if t and t.is_alive() and t is not threading.current_thread(): t.join(timeout=0.5)
        self.thread=None
    def _run(self,initial_cfg,generation):
        while not self._stop.is_set() and generation==self.generation:
            cfg=dict(getattr(self.host,'runtime_cfg',None) or initial_cfg)
            try:
                if cfg.get('spotify_watchdog_parity_enabled',True):
                    hwnd=self.host._spotify_cached_game_hwnd()
                    if hwnd:
                        frame=self.host._spotify_watchdog_capture_frame(cfg,hwnd)
                        if frame is not None:
                            for result in self.host._spotify_watchdog_scan_frame(frame,cfg):
                                if result.matched: self.host._spotify_watchdog_emit(result,cfg)
            except Exception as exc:
                self.host._log(f'[Spotify Watchdog] scan error: {exc}')
            self._stop.wait(self.host._spotify_watchdog_interval(cfg))
```

def _spotify_watchdog_interval(self,cfg):
    fps=max(1.0,float(cfg.get('fps',8.0)))
    detect_every=max(1,int(cfg.get('detect_every',1)))
    return max(0.01,detect_every/fps)

def _spotify_watchdog_capture_frame(self,cfg,hwnd):
    if not hwnd: return None
    return self.capture_screen(cfg['region'],fast=cfg.get('use_fast_capture',True))

def _spotify_watchdog_scan_frame(self,frame,cfg):
    bgr=cv2.cvtColor(frame,cv2.COLOR_RGB2BGR); gray=cv2.cvtColor(bgr,cv2.COLOR_BGR2GRAY)
    results=[]
    specs=(('dead','dead_template','alert_threshold','cached_dead'),
           ('dc','dc_template','alert_threshold','cached_dc'),
           ('captcha','captcha_template','alert_threshold','cached_captcha'),
           ('full_bag','full_template','threshold','cached_full'))
    for kind,path_key,threshold_key,cache_name in specs:
        path=str(cfg.get(path_key) or '').strip()
        threshold=float(cfg.get(threshold_key,0.86 if threshold_key=='alert_threshold' else 0.6))
        box=self.find_best(gray,path,threshold,cfg.get('nms_distance',35),cfg) if path else None
        setattr(self,cache_name,box)
        score=float(box[0]) if box else 0.0
        results.append(score_result(kind,score,threshold,SOURCE_NGHIA_FALLBACK))
    return results

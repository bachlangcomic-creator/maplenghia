# Nghia V10.0.1 Spotify Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** improve legacy-map runtime stability to better match Spotify while leaving Strategy V10/map-new features untouched.

**Architecture:** build from the verified public V10.0.0 portable candidate, apply a narrow deterministic transform to legacy runtime source only, then rebuild the Windows onefile app. The patch changes lost-position arbitration and the fresh C2 lane default; all Strategy V10 and map data stay hash-locked.

**Tech Stack:** Python 3.12, Tkinter/CustomTkinter host UI, Nuitka, PowerShell, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-14-v10.0.1-spotify-stability-design.md`

## Global Constraints

- Version: `10.0.1`.
- Public V10.0.0 portable is the source baseline.
- `nghia_strategy_v10.py` SHA-256 must stay `6066d1ec948b7e9783944a1c2825a033061b1e130fde44b3799783263b1da9b8`.
- `maps.json` SHA-256 must stay `52364dc3a284e051a04263b49e008caf699de9127cc62c8c59b7a8bb6533671d`.
- No new map/combat/TP/loot modes.
- No public `latest.json` update until explicit approval after candidate verification.

### Task 2: Apply minimal Spotify-stability correction

**Files:**
- Create: `build_input/apply_v1001.py`
- Modify at build time: `portable/app_payload/spotify_recovered_core.py`
- Modify at build time: `portable/app_payload/maple_nghia_pro.py`
- Modify at build time: `portable/app_payload/nghia_spotify_nologin.py`

**Interfaces:**
- Consumes verified V10.0.0 source hashes.
- Produces deterministic LF-normalized V10.0.1 source.

- [ ] **Step 1: Correct lost-position arbitration**

In `_spotify_recovery_layer_step`, exact `spotify_runtime_parity_mode=True` must let `_spotify_worker_reacquire_reconstructed()` own the 3.0-second random-move stage. Generic `_spotify_recovery()` is deferred until `SPOTIFY_RECOVERY_POSITION_HARD` (4.5 s). Non-parity mode keeps the prior 3.0-second soft fallback.

- [ ] **Step 2: Change fresh C2 default only**

Change `self.c2_adaptive_y_enabled = tk.BooleanVar(value=True)` to `value=False`. Do not alter `load_config`: an explicit saved `c2_adaptive_y_enabled` value continues to overwrite the default.

- [ ] **Step 3: Bump visible version**

Replace V10.0.0 identity strings in `nghia_spotify_nologin.py` with V10.0.1 only; no updater/public-channel mutation.

- [ ] **Step 4: Assert hard isolation**

After transformation, SHA-256 of `nghia_strategy_v10.py` and `maps.json` must exactly match the V10.0.0 baseline hashes above.

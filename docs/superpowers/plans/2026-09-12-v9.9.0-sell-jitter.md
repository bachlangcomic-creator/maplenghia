# Nghia V9.9.0 Auto-Sell Jitter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace V9.8.1 fixed sell scheduling with the recovered High-structural Spotify jitter formula while keeping the watchdog as the sole timer owner and exposing one pending sell-due request to the farm loop.

**Architecture:** Replace the V9.8 watchdog module with a V9.9 copy that computes one randomized delay and latches a pending due state. The existing host `spotify_sell_timer_event` remains the cross-subsystem request signal. Reaching SAFE_PLACE only dispatches the seller; it does **not** mark the schedule complete. The watchdog schedule resets only from the real sell worker's success path.

**Tech Stack:** Python 3.12, `random.uniform`, `time.monotonic`, pytest, existing host sell thread/MiuMiu seller.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.9.0-forensic-parity-design.md`

## Global Constraints

- Base artifact: public `NghiaClient_V9.8.1_Portable.zip`, SHA-256 `e36350ab7e8285f3e7f0c4d1cc80aee9c88d4c5927249bb11dcc40b989694d46`.
- Literal evidence `10`, `10`, `max`, `1.2`, `random.uniform`, `60` is Direct.
- Formula `uniform(max(10,m-10), m*1.2) * 60` is **High-structural**, never Direct.
- Watchdog is the only sell timer owner; the main-farm orchestrator must not compute a second delay.
- Timer maturity creates one pending request; it does not call MiuMiu directly.
- SAFE_PLACE READY does not equal sell success.
- Only the existing seller's confirmed-success path may call `spotify_watchdog.notify_sell_completed(...)`.
- Failed/cancelled seller attempts must not falsely reset the randomized schedule as a success.
- Disabling auto-sell clears stale delay and pending state.
- Do not change MiuMiu image matching, safe-place verification, cooldown, or full-bag detector semantics.

import random


def get_next_sell_delay(self, cfg):
    minutes = max(0.0, float(cfg.get("sell_interval_minutes", 30.0)))
    low_minutes = max(10.0, minutes - 10.0)
    high_minutes = minutes * 1.2
    if high_minutes < low_minutes:  # Nghia fallback only
        high_minutes = low_minutes
    return random.uniform(low_minutes, high_minutes) * 60.0, "spotify_structural"

```python
def _sell_schedule_step(self, cfg):
    if not cfg.get("auto_sell_timer_enabled"):
        self.next_sell_delay = None
        self.sell_due_pending = False
        self.last_sell_time = time.monotonic()
        return
    if self.sell_due_pending:
        return
    if self.next_sell_delay is None:
        self.next_sell_delay, _source = self.get_next_sell_delay(cfg)
    now = time.monotonic()
    if now - self.last_sell_time < self.next_sell_delay:
        return
    self.sell_due_pending = True
    self.host._spotify_watchdog_sell_timer_due(cfg)


def notify_sell_completed(self, now=None):
    self.last_sell_time = time.monotonic() if now is None else float(now)
    self.next_sell_delay = None
    self.sell_due_pending = False
```

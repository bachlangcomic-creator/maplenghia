# Nghia V9.9.0 Main Farm Orchestrator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reconstruct the evidenced `main_farm_worker` responsibility order inside Nghia's existing farm loop without inventing a Spotify thread or duplicating watchdog/focus timers.

**Architecture:** Add a small orchestration module whose only job is ordered stage dispatch. `MapleNghiaPro` keeps the existing sell/safe-place, pet, recovery, buff, and behavior-engine implementations behind explicit host stage methods. The orchestrator never generates timing, never marks a sell complete, and returns immediately when a safety/sell/recovery stage consumes the tick.

**Tech Stack:** Python 3.12, pytest, static AST guards, existing Maple host + `SpotifyBehaviorEngine`.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.9.0-forensic-parity-design.md`

## Global Constraints

- Do not create `Nghia-Spotify-MainFarm` or any new farm thread.
- Do not add `session_monitor_worker` or any session/login/license path.
- Stage order is exactly: state gate -> pending sell/safe-place -> pet -> lost-player recovery -> buff1 -> buff2 -> farm dispatch.
- Watchdog remains the sole sell-timer owner; orchestrator/stages contain no `random.uniform`, `sell_interval_minutes`, or next-delay generation.
- SAFE_PLACE/seller dispatch does not call `spotify_watchdog.notify_sell_completed`; completion belongs to the confirmed seller-success path from the Sell Jitter plan.
- Focus remains owned by the existing focus path; orchestrator contains no `EnumWindows`, `_find_game_window`, or focus thread.
- C2 Fast Worker remains isolated from watchdog/market/MiuMiu side effects.
- V9.8.1 C1/C2/B1/B3 hold-combo semantics remain unchanged.

CONTINUE = "CONTINUE"
STOP_TICK = "STOP_TICK"


class SpotifyMainFarmOrchestrator:
    def __init__(self, host): self.host = host
    def tick(self, cfg, map_pos, now):
        stages=(
            self.host._spotify_mainfarm_state_stage,
            self.host._spotify_mainfarm_sell_safe_stage,
            self.host._spotify_mainfarm_pet_stage,
            self.host._spotify_mainfarm_recovery_stage,
            self.host._spotify_mainfarm_buff1_stage,
            self.host._spotify_mainfarm_buff2_stage,
            self.host._spotify_mainfarm_dispatch_stage,
        )
        for stage in stages:
            if stage(cfg, map_pos, now) == STOP_TICK:
                return STOP_TICK
        return CONTINUE

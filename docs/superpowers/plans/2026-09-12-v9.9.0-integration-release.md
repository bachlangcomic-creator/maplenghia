# Nghia V9.9.0 Integration and Release Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Assemble the five independently tested V9.9 forensic-parity changes on the exact public V9.8.1 base, run Windows/private preflight, and keep public publishing locked behind explicit user approval.

**Architecture:** GitHub Actions downloads and SHA-gates public V9.8.1, applies/copies V9.9 overlay modules and cumulative patches, runs V9.7/V9.8/V9.8.1/V9.9 regressions, then packages private artifacts. Public release steps are manual `workflow_dispatch` with `publish=true`; public assets are re-downloaded and SHA-verified before `latest.json` is generated and committed last.

**Tech Stack:** GitHub Actions `windows-latest`, Python 3.12, pytest, PowerShell, `git apply`, GitHub CLI, ZIP/SHA-256 verification.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.9.0-forensic-parity-design.md`

- [ ] **Step 3: Implement overlay script**

```powershell
param([Parameter(Mandatory=$true)][string]$PortableRoot)
$ErrorActionPreference='Stop'
$root=(Resolve-Path $PortableRoot).Path
$app=Join-Path $root 'app_payload'
$overlay=Split-Path -Parent $MyInvocation.MyCommand.Path

$copies=@(
  'spotify_detection_parity.py','spotify_watchdog.py','spotify_all_cure_assets.py',
  'spotify_all_cure_executor.py','spotify_all_cure_market.py','spotify_main_farm_orchestrator.py'
)
foreach($name in $copies){ Copy-Item (Join-Path $overlay $name) (Join-Path $app $name) -Force }

# Normalize LF only for the two patch targets before git apply, matching V9.8.1 workflow behavior.
foreach($target in @('spotify_recovered_core.py','maple_nghia_pro.py')){
  $path=Join-Path $app $target
  $text=[IO.File]::ReadAllText($path).Replace("`r`n","`n")
  [IO.File]::WriteAllText($path,$text,[Text.UTF8Encoding]::new($false))
}
foreach($patch in @('spotify_recovered_core.patch','maple_nghia_pro.patch')){
  git apply --check --directory=$app (Join-Path $overlay $patch)
  if($LASTEXITCODE -ne 0){ throw "$patch check failed" }
  git apply --directory=$app (Join-Path $overlay $patch)
  if($LASTEXITCODE -ne 0){ throw "$patch apply failed" }
}
New-Item -ItemType Directory -Force (Join-Path $app 'evidence') | Out-Null
Copy-Item (Join-Path $overlay 'evidence/*.json') (Join-Path $app 'evidence') -Force
```

The script must contain no write/remove/copy destination under `user_data`.

# Nghia V9.9.0 Integration and Release Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Assemble the five independently tested V9.9 forensic-parity overlays on the exact public V9.8.1 base, run complete Windows/private preflight verification, and keep public publishing locked behind explicit user approval.

**Architecture:** GitHub Actions downloads and SHA-gates public V9.8.1, applies/copies V9.9 overlay modules and cumulative patches, then runs V9.7/V9.8/V9.8.1/V9.9 regressions before packaging. Public release steps are `workflow_dispatch`-only with `publish=true`; public assets are re-downloaded and SHA-verified before `latest.json` is updated last.

**Tech Stack:** GitHub Actions `windows-latest`, Python 3.12, pytest, PowerShell, `git apply`, GitHub CLI Releases, ZIP/SHA-256 validation.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.9.0-forensic-parity-design.md`

## Global Constraints

- Public V9.8.1 Portable base SHA-256: `e36350ab7e8285f3e7f0c4d1cc80aee9c88d4c5927249bb11dcc40b989694d46`.

- Public version/tag: `v9.9.0`; artifacts: `NghiaClient_V9.9.0_Portable.zip`, `NghiaEdition_Update_v9.9.0.zip`.

- [ ] **Step 3: Implement overlay script after all five subplans are GREEN**

```powershell
param([Parameter(Mandatory=$true)][string]$PortableRoot)
$ErrorActionPreference='Stop'
$root=(Resolve-Path $PortableRoot).Path
$app=Join-Path $root 'app_payload'
$overlay=Split-Path -Parent $MyInvocation.MyCommand.Path

$copies=@(
  'spotify_detection_parity.py','spotify_watchdog.py','spotify_all_cure_assets.py',
  'spotify_all_cure_market.py','spotify_main_farm_orchestrator.py'
)
foreach($name in $copies){ Copy-Item (Join-Path $overlay $name) (Join-Path $app $name) -Force }

git apply --check --directory=$app (Join-Path $overlay 'spotify_recovered_core.patch')
if($LASTEXITCODE -ne 0){ throw 'core patch check failed' }
git apply --directory=$app (Join-Path $overlay 'spotify_recovered_core.patch')
if($LASTEXITCODE -ne 0){ throw 'core patch apply failed' }

git apply --check --directory=$app (Join-Path $overlay 'maple_nghia_pro.patch')
if($LASTEXITCODE -ne 0){ throw 'host patch check failed' }
git apply --directory=$app (Join-Path $overlay 'maple_nghia_pro.patch')
if($LASTEXITCODE -ne 0){ throw 'host patch apply failed' }

New-Item -ItemType Directory -Force (Join-Path $app 'evidence') | Out-Null
Copy-Item (Join-Path $overlay 'evidence/*.json') (Join-Path $app 'evidence') -Force
```

Before patching, normalize CRLF to LF only for the two patch targets, exactly as V9.8.1 workflow did. Do not rewrite unrelated production files.

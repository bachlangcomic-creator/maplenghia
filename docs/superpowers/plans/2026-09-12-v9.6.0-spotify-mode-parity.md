# Nghĩa V9.6.0 Spotify Mode Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build V9.6.0 from the verified V9.5.0 Focus Parity A portable base, improve Spotify parity for C1/B1/B3/Bunny/C1 Stand Still/Pirate2/Pirate2 1 Hit, and prove C2 timing/focus behavior does not regress.

**Architecture:** Keep the current release-overlay model. GitHub Actions downloads `NghiaClient_V9.5.0_Portable.zip`, verifies its published SHA-256, extracts it, applies only V9.6.0 behavior patches, runs deterministic unit/regression tests against the staged `app_payload`, performs the real Windows launcher smoke, then publishes V9.6.0 assets. Mode routing remains in `spotify_behavior_engine.py`; recovered constants and state-machine logic remain in `spotify_recovered_core.py`; `maple_nghia_pro.py` is changed only where profile/config bridges require it.

**Tech Stack:** Python 3.12, pytest, Git patch overlays, PowerShell, GitHub Actions on `windows-latest`, existing Nghia launcher/updater packaging.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.6.0-spotify-mode-parity-design.md`

## Global Constraints

- Base release is public stable `v9.5.0`; published portable SHA-256 is `1fa0af1193ba49e4a056b70eb5f6a82b1a61b6f2f38c7b8b0cc825490d9ad013`.
- Do not change the C2 core sequence: movement held -> Teleport 20..50 ms -> Skill 20..50 ms -> pair wait 0.05..0.15 s -> repeat within outer 200..500 ms.
- Keep PyDirectInput `PAUSE = 0.1` behavior unless direct later evidence disproves it.
- Keep V9.5.0 Focus Parity A: dedicated ~0.2 s focus worker; combat/C2 hot paths use cached focus state only.
- Keep MiuMiu seller, PC Alarm, launcher/updater, user-data preservation, config migration, and verified launcher icon unchanged.
- C1/B1/B3 share only the recovered SIMPLE movement/edge/fall family; do not automatically force C2 Combo-2 semantics onto them.
- B3 fixed-Y is the Spotify-parity path; Adaptive Y remains a Nghĩa extension and must be labeled as such.
- Bunny, Stand Still, Pirate2, and Pirate2-1Hit remain dedicated state machines.
- Do not invent a Bunny B_Y constant or any hidden fixed post-loot Stand Still anchor.
- STOP, focus fail-safe, generation change, and restart must release behavior-owned movement/teleport/skill inputs.
- V9.5.0 release is immutable; publish V9.6.0 as a new release.

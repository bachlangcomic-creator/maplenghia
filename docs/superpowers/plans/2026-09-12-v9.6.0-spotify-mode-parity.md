# Nghĩa V9.6.0 Spotify Mode Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build V9.6.0 from the verified V9.5.0 Focus Parity A portable base, improve Spotify parity for C1/B1/B3/Bunny/C1 Stand Still/Pirate2/Pirate2 1 Hit, and prove C2 timing/focus behavior does not regress.

**Architecture:** Preserve the current release-overlay model. GitHub Actions downloads `NghiaClient_V9.5.0_Portable.zip`, verifies its published SHA-256, extracts it, applies V9.6.0 patches to `app_payload`, runs deterministic pytest regression tests, performs the real Windows launcher smoke, packages the portable/update ZIPs, verifies public asset hashes, and only then updates `latest.json`. Mode routing stays in `spotify_behavior_engine.py`; recovered constants/state machines stay in `spotify_recovered_core.py`; `maple_nghia_pro.py` is touched only for profile/config bridges.

**Tech Stack:** Python 3.12, pytest, Git patch overlays, PowerShell, GitHub Actions `windows-latest`, existing Nghia launcher/updater packaging.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.6.0-spotify-mode-parity-design.md`

## Global Constraints

- Base release: public stable `v9.5.0`; portable SHA-256 `1fa0af1193ba49e4a056b70eb5f6a82b1a61b6f2f38c7b8b0cc825490d9ad013`.
- Preserve C2: movement held -> Teleport 20..50 ms -> Skill 20..50 ms -> wait 0.05..0.15 s -> repeat inside outer 200..500 ms.
- Preserve PyDirectInput `PAUSE = 0.1`.
- Preserve V9.5.0 Focus Parity A: dedicated ~0.2 s focus worker; combat/C2 reads cached focus only.
- Keep MiuMiu, PC Alarm, launcher/updater, user-data preservation, config migration, and launcher icon unchanged.
- C1/B1/B3 share only SIMPLE movement/edge/fall structure; do not force C2 Combo-2 semantics onto them.
- B3 fixed-Y is the parity path; Adaptive Y remains a Nghĩa extension.
- Bunny, Stand Still, Pirate2, and Pirate2-1Hit remain dedicated state machines.
- Do not invent Bunny B_Y or a fixed Stand Still post-loot anchor.
- STOP/restart/generation change must leave no behavior-owned key held.
- Never overwrite V9.5.0; publish V9.6.0 separately.

import ast
from pathlib import Path

def function_source(path,name):
    text=Path(path).read_text(encoding="utf-8")
    tree=ast.parse(text)
    for node in ast.walk(tree):
        if isinstance(node,(ast.FunctionDef,ast.AsyncFunctionDef)) and node.name==name:
            return ast.get_source_segment(text,node)
    raise AssertionError(name)

def test_focus_worker_keeps_window_lookup_out_of_combat():

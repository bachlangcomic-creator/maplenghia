# Nghia V9.8.1 Hold Combo Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the active SIMPLE/Pirate combat path with the recovered Spotify `hold_combo_action` semantics for C1/C2/B1/B3 and Pirate Den, while preserving Pirate Den 1 Hit’s one-hit FARM state machine and all V9.8.0 protected subsystems.

**Architecture:** Build V9.8.1 as an overlay on the exact public V9.8.0 Portable release. Keep the old Dynamic Combo helpers/constants present for forensic and V9.7 regression compatibility, but remove them from active SIMPLE/Pirate callers. Implement one shared `SpotifyRecoveredCore._spotify_hold_combo_action(self, cfg, direction_key, flash_key, skill_key, hold_time)` primitive, then route SIMPLE and Pirate normal callers to it with evidence-backed windows and route Pirate 1 Hit only through it during loot sweep.

**Tech Stack:** Python 3.12, pytest, GitHub Actions on `windows-latest`, GitHub Releases, existing Nghia input bridge (`SpotifyRecoveredCore`, `SpotifyBehaviorEngine`, `MapleNghiaPro`).

**Spec:** `docs/superpowers/specs/2026-09-12-v9.8.1-hold-combo-parity-design.md`

## Global Constraints

- Base artifact is exactly public `NghiaClient_V9.8.0_Portable.zip` with SHA-256 `12162a83986e8f9ff322a5e9735a4d8ef1989526dd85638051206a570be4caa1`.
- Do not mutate or replace public V9.8.0 assets.
- `hold_time` is seconds at the helper boundary; 200–500 ms evidence is passed as randomized `0.200–0.500` seconds.
- Shared action order is Teleport/Flash tap → random 15–45 ms → Skill tap → random 125–255 ms, repeating until the combo window expires.
- If Teleport is disabled or unavailable, caller passes `flash_key=None`; the helper falls back to Skill-only without failing the route.
- C1/C2/B1/B3 active FARM uses the shared helper with randomized `0.200–0.500` s.
- Pirate Den normal FARM uses randomized `0.200–0.500` s; normal loot sweep uses exactly `1.6` s.
- Pirate Den 1 Hit FARM must remain one-hit and must not call the shared spam helper; its loot sweep uses exactly `1.5` s.
- Keep `_spotify_c2_tp_skill_hold_combo`, `SPOTIFY_R54_COMBO_SPAM_ACTION_MS = (20, 50)`, and `SPOTIFY_R54_COMBO_SPAM_WAIT_S = (0.05, 0.15)` present but inactive so V9.7 regression tests and forensic evidence remain valid.
- Dynamic Combo remains dormant/evidence-gated for these production callers.
- Pirate Laptop is out of scope and must not be routed, implemented, or tested as a V9.8.1 feature.
- Preserve existing SIMPLE map bounds, C2 cached-HWND/focus path, adaptive-Y settings, recovery, safe-place logic, MiuMiu, watchdog, detector assets/thresholds, revive, All Cure, launcher/update, and session-exclusion behavior.
- Do not add `session_monitor_worker`, `check_session`, session token enforcement, KICK-driven disable controls, CAPTCHA solver, Gemini integration, or automated CAPTCHA answering.
- Public release remains gated by explicit user approval after a successful private preflight.

```python
def _spotify_hold_combo_action(self, cfg, direction_key, flash_key, skill_key, hold_time):
    if not skill_key:
        self._log("[Spotify Combo] missing skill key; combat skipped")
        return False

    self.set_move(direction_key)
    end_time = time.monotonic() + max(0.0, float(hold_time))
    try:
        while time.monotonic() < end_time:
            if flash_key:
                self._spotify_input_semantic(cfg, "FLASH", flash_key)
                time.sleep(random.uniform(0.015, 0.045))
            self._spotify_input_semantic(cfg, "SKILL", skill_key)
            time.sleep(random.uniform(0.125, 0.255))
        return True
    except Exception:
        self._release_all_owned_inputs()
        raise
```

If the current input bridge uses a different existing semantic label for Teleport/Skill, reuse that exact existing label rather than introducing a new backend path. Do not call `pydirectinput` directly from this helper.

Do not release the movement direction at normal helper return; route/state code still owns movement continuity and edge reversal. Cleanup on stop/error must continue through the existing generation/input-ownership path.

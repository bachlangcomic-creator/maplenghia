# Nghia V9.8.1 Hold Combo Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the active SIMPLE/Pirate combat path with the recovered Spotify `hold_combo_action` semantics for C1/C2/B1/B3 and Pirate Den, while preserving Pirate Den 1 Hit’s one-hit FARM state machine and all V9.8.0 protected subsystems.

**Architecture:** Build V9.8.1 as an overlay on the exact public V9.8.0 Portable release. Keep the old Dynamic Combo/C2-SPAM helper and constants present for forensic and regression compatibility, but remove them from active SIMPLE/Pirate callers. Implement one shared `SpotifyRecoveredCore._spotify_hold_combo_action(self, cfg, direction_key, flash_key, skill_key, hold_time)` primitive, route SIMPLE and Pirate normal callers to it, and route Pirate Den 1 Hit through it only during loot sweep.

**Tech Stack:** Python 3.12, pytest, GitHub Actions on `windows-latest`, GitHub Releases, existing Nghia input bridge (`SpotifyRecoveredCore`, `SpotifyBehaviorEngine`, `MapleNghiaPro`).

**Spec:** `docs/superpowers/specs/2026-09-12-v9.8.1-hold-combo-parity-design.md`

## Global Constraints

- Base artifact: public `NghiaClient_V9.8.0_Portable.zip`, SHA-256 `12162a83986e8f9ff322a5e9735a4d8ef1989526dd85638051206a570be4caa1`.
- Do not mutate or replace public V9.8.0 assets.
- `hold_time` is seconds at the helper boundary.
- Shared action order: Teleport/Flash tap → random `0.015–0.045` s → Skill tap → random `0.125–0.255` s → repeat until `hold_time` expires.
- If Teleport is disabled/unavailable, caller passes `flash_key=None`; helper becomes Skill-only without failing the route.
- C1/C2/B1/B3 FARM: randomized `0.200–0.500` s shared combo window.
- Pirate Den normal FARM: randomized `0.200–0.500` s; normal loot sweep: exactly `1.6` s.
- Pirate Den 1 Hit FARM remains one-hit and must not call the shared spam helper; its loot sweep uses exactly `1.5` s.
- Keep `_spotify_c2_tp_skill_hold_combo`, `SPOTIFY_R54_COMBO_SPAM_ACTION_MS = (20, 50)`, and `SPOTIFY_R54_COMBO_SPAM_WAIT_S = (0.05, 0.15)` present but inactive.
- Dynamic Combo remains dormant/evidence-gated for these production callers.
- Pirate Laptop is out of scope.
- Preserve SIMPLE bounds, C2 cached-HWND/focus/adaptive-Y/recovery, safe-place, MiuMiu, watchdog, detectors, revive, All Cure, launcher/update, and session-exclusion behavior.
- Do not add `session_monitor_worker`, `check_session`, session token enforcement, KICK-driven disable controls, CAPTCHA solver, Gemini, or automated CAPTCHA answering.
- Public release requires explicit user approval after a successful private preflight.

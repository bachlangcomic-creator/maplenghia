# Nghia V9.9.0 All Cure External Asset Gateway Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep All Cure fail-closed with the supplied package while making the core data-driven: original external PNGs go in `user_data/all_cure_images/`, workflow parameters live in evidence JSON, and no future core rewrite is needed when missing external evidence becomes available.

**Architecture:** Add a strict external-asset gateway plus a generic evidence-driven executor. The worker has three gates: config enabled, assets READY, workflow evidence READY. The executor never contains guessed per-step thresholds/timings; it consumes only validated action records from `all_cure_market.json`. If any required execution parameter remains unresolved, workflow READY is false and zero market clicks occur. New evidence can later be supplied by updating the JSON rather than rewriting the executor.

**Tech Stack:** Python 3.12 stdlib (`pathlib`, `struct`, `zlib`, `binascii`, `json`), pytest, existing host matcher/input bridges.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.9.0-forensic-parity-design.md`

## Global Constraints

- Asset directory is exactly `user_data/all_cure_images/`, outside `app_payload`.
- Required exact filenames: `empty.png`, `npc_all_cure.png`, `all_cure_line.png`, `confirm_all_cure.png`, `buy_all_cure.png`, `finish_buying.png`, `shop.png`, `exit.png`, `all_cure_pots.png`, `set_sell_item.png`, `confirm_set_item_to_sell.png`, `complete_set_item.png`.
- Missing/invalid PNG or disabled config => BLOCKED and zero `_spotify_market_run_action` calls.
- Do not synthesize images, rename approximate images, use OCR, or fall back to coordinate-only clicking.
- Updater/package overlay must not overwrite/delete `user_data/all_cure_images/`.
- Original 12 PNGs are absent from supplied Spotify package; no pixel-identical claim is allowed until originals are supplied and independently verified.
- Evidence labels are only `direct`, `high_structural`, `nghia_fallback`.
- Generic executor accepts no action that lacks its required evidence fields. `None` in an action record is an intentional unresolved value and makes workflow READY false; it is not a placeholder.

```python
import binascii, struct, zlib


def chunk(kind,data):
    body=kind+data
    return struct.pack('>I',len(data))+body+struct.pack('>I',binascii.crc32(body)&0xffffffff)


def tiny_png():
    sig=b'\x89PNG\r\n\x1a\n'
    ihdr=struct.pack('>IIBBBBB',1,1,8,0,0,0,0)
    return sig+chunk(b'IHDR',ihdr)+chunk(b'IDAT',zlib.compress(b'\x00\x00'))+chunk(b'IEND',b'')
```

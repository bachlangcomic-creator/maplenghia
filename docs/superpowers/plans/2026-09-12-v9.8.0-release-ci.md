# Nghĩa V9.8.0 Release, CI & Publication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, package, preflight, and—only after explicit approval—publish V9.8.0 from the exact public V9.7.0 stable base.

**Architecture:** GitHub Actions downloads public V9.7.0 Portable, verifies its SHA and protected source/component hashes, applies the V9.8 overlay, runs compile/tests/protected guards, launches the real Windows client, packages Portable/Update archives, and uploads private preflight artifacts. Public release creation, public redownload/hash verification, and `main/latest.json` update are hard-gated behind `publish=true` and explicit user approval.

**Tech Stack:** GitHub Actions Windows runner, PowerShell, Python 3.12, pytest, GitHub CLI, ZIP/SHA-256 packaging, existing Nghia launcher/updater.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.8.0-exact-detector-watchdog-recovery-design.md`

## Global Constraints

- Requires Plans 1–3 to be complete and green.
- Public V9.7.0 Portable SHA-256: `09f70ba29b5a55aa84c040c195d3ab629259214f3c745105e691678d225b0086`.
- V9.7 source baseline hashes before V9.8 overlay: `maple_nghia_pro.py=fe7821832fe4e4a6d163c69163d2dbddf5578c6030919a3014e64a355f3d3194`, `spotify_recovered_core.py=eaf052e9891a018c43f8dd51fb992ea75525855859754f73112fccbf46217aed`, `spotify_behavior_engine.py=3a6cc1e9ffaaae036c8625706aead23f5f85305a1a9de1165167240c9cae89db`.

- V9.8 release must contain no active session-monitor/login/license/session enforcement and no CAPTCHA solver.
- Public release/tag/`main/latest.json` mutation is forbidden before explicit user approval after a successful private preflight.

### Task 2: Add Windows Preflight/Publish Workflow

**Files:**
- Create: `.github/workflows/publish-v9.8.0.yml`

**Interfaces:**
- Input: `workflow_dispatch.inputs.publish` boolean, default `false`.
- Output preflight artifacts: `NghiaClient_V9.8.0_Portable.zip`, `NghiaEdition_Update_v9.8.0.zip`, `latest.json`.

- [ ] **Step 1: Copy V9.7 workflow structure and change the base/release contract**

Workflow header:

```yaml
name: Publish Nghia Client v9.8.0 Spotify Exact Detector Watchdog Recovery
on:
  workflow_dispatch:
    inputs:
      publish:
        description: 'Create public v9.8.0 release and publish latest.json'
        required: true
        type: boolean
        default: false
permissions:
  actions: read
  contents: write
env:
  REPO: bachlangcomic-creator/maplenghia

```

Checkout branch: `release-v9.8.0-exact-detector-watchdog-recovery`.

- [ ] **Step 2: Download and hash-gate public V9.7.0 Portable**

Use:


Python check must compare against `09f70ba29b5a55aa84c040c195d3ab629259214f3c745105e691678d225b0086`, extract to `portable`, then hash-gate the three V9.7 source files using the Global Constraints values.

- [ ] **Step 3: Apply V9.8 overlay and run all tests**

```powershell
$env:APP_PAYLOAD=(Resolve-Path portable/app_payload).Path
```

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace V9.7 detector fallbacks with hash-locked Spotify assets and evidence-labeled detector paths without adding any CAPTCHA solver behavior.

**Architecture:** Keep exact asset bytes in a side-effect-free module and keep detector policy in `spotify_detection_parity.py`. Detector helpers accept deterministic matcher callbacks so unit tests do not depend on a live game window. Exact labeling is allowed only when both asset identity and path evidence are satisfied; otherwise the result remains `spotify_structural` or `nghia_fallback`.

**Tech Stack:** Python 3.12, pytest, OpenCV-compatible image arrays at runtime, hashlib/base64, existing V9.7 overlay packaging.

**Spec:** `docs/superpowers/specs/2026-09-12-v9.8.0-exact-detector-watchdog-recovery-design.md`

Module API:

```python
import base64, hashlib

def decode_exact_asset(name: str) -> bytes:
    return base64.b64decode(EXACT_ASSET_B64[name], validate=True)

def verify_exact_asset(name: str) -> bool:
    raw = decode_exact_asset(name)
    return hashlib.sha256(raw).hexdigest() == EXACT_ASSET_SHA256[name]
```

```python
def exact_asset_result(kind, score, threshold, asset_name, *, path_is_exact):
    if not verify_exact_asset(asset_name):
        raise ValueError("exact Spotify asset hash mismatch")
    source = SOURCE_EXACT if path_is_exact else SOURCE_STRUCTURAL
    return score_result(kind, score, threshold, source, exact_asset=(source == SOURCE_EXACT))

def detect_captcha_exact(frame, game_size, matcher):
    roi = crop_captcha_roi(frame, game_size)
    score = float(matcher(roi, decode_exact_asset("LIE_B64")))
    return exact_asset_result("captcha", score, CAPTCHA_PRIMARY_THRESHOLD, "LIE_B64", path_is_exact=True)
```

For dead, online/disconnect, and full-bag variants, do not fabricate a crop. The scorer takes an already-produced score and requires an explicit `path_is_exact` boolean from a call site whose geometry/path was separately recovered. Full-bag threshold remains `0.35`; MiuMiu `SELL_THRESHOLD` remains `0.65`.
